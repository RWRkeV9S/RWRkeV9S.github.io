奶龙比可爱

非常ez的签到题！（虽然本场签到其实不是a而是e）

奶龙可比爱

（哪个天才想出来的题目名字！？）

因为要求总和最小，且每个奶龙的可爱度不能重复，所以每个奶龙的可爱度一定是 0,1,2,…,n−1

对于第 i 只奶龙，ai​ 表示它左边有多少只奶龙比它可爱度小。

我们从左到右构造。维护一个列表 b，表示当前已经确定的奶龙按可爱度从小到大排列的位置。

当处理第 i 只奶龙时：

  • 它左边已经有 i 只奶龙；

  • 其中有 ai​ 只比它小；

  • 所以它在当前有序列表中的插入位置就是 ai​。

插入完成后，最终 b 中第 k 个位置对应的奶龙，可爱度就是 k。

实验室制取水

第一直觉是跟 gcd 会相关，先设一个 d=gcd(a,b)，那我们就可以注意到，三种操作：

  • 倒满：桶里变成 0 或 a 或 b，都是 d 的倍数；

  • 倒空：变成 0，也是 d 的倍数；

  • 互相倒：两个桶水量做加减，仍然是 d 的倍数。

所以无论怎么操作，任意时刻两个桶里的水量都一定是 d 的倍数。

因此如果目标 c 不是 d 的倍数，绝对量不出来。

可以得到 cmodd=0。至于其他就是根据数据范围得出的一些特判了。

二进制王国

真正的签到！

设原数组的异或和为：

S=x1​⊕x2​⊕⋯⊕xn​

假设我们修改第 i 个数 xi​ 为 y，修改后的异或和为：

S⊕xi​⊕y

要让它等于 0，则：

S⊕xi​⊕y=0

即：

y=S⊕xi​

题目要求修改后的数不能等于原来的数，因此需要：

S⊕xi​=xi​

这个条件等价于：

S=0

所以：

  • 如果原数组异或和 S=0，一定存在合法修改方案，输出 YES；

  • 如果原数组异或和 S=0，无论改哪个数，要使异或和变为 0 都必须保持原数不变，但题目要求必须修改且不能等于原值，因此输出 NO。

城邦争霸

这个就要思考怎么买堡垒才能赚。

假设当前的时间为 t，我们花费 x 个士兵买了一个堡垒。此时游戏剩余时间为 m−t，因为每个堡垒每秒会生产一个士兵，所以他在剩余时间内带来的收益是 m−t，所以他的净收益就是 m−t−x，只有净收益大于 0 的时候，我们才能购买这个堡垒。

评价喵

这里是写完之后来做了一个我认为这场的最优做题策略，仅仅是我认为

  • c：这里可以冒泡排序混完60分就走，当然会写归并的话应该也是可以的

  • e：跟榜走是对的，这个是真签到

  • d：带草稿纸的话，简单推一下样例，很容易得到一个 3a−b=c 的错误式子。但值得注意的是，这个式子可以得到35分，哪怕你没有发现出题人挖的坑，也可以骗走15分。

  • b：b 很容易想到 n2 的做法，而出题人非常善良的把 n2 放过去了
